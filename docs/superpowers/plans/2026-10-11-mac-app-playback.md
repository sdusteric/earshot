# Earshot for Mac, plan 1: playback app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-ready menu bar app that takes over playback from the plugin (queue, holding during calls, catch-up, voices, lowering other audio), plus the plugin handoff and shorter spoken session names.

**Architecture:** A Swift package, `EarshotKit`, holds every non-UI part and is tested with `swift test`. A thin Xcode app target (generated by XcodeGen) holds the menu bar, settings, onboarding and Sparkle. `speak.sh` offers each line to the app over a Unix socket and plays it itself when the app does not answer within 200 ms.

**Tech Stack:** Swift 6.2+ (toolchain 6.4), macOS 26 SDK, Swift Testing, FluidAudio 0.17.7 (Kokoro), Core Audio process taps, AVFoundation, SwiftUI `MenuBarExtra`, Sparkle 2, XcodeGen, bash 3.2 and zsh for the plugin.

**Spec:** `docs/superpowers/specs/2026-10-11-mac-app-design.md`

This is plan 1 of 2. Plan 2 (written after this one ships) covers listening: the wake word power probe, wake word and hotkey, transcription, the Foundation Model parser, SessionDirectory, Dispatcher, the four commands, and the app-made session labels.

## Global Constraints

- macOS 26 or later for the app (`platforms: [.macOS(.v26)]`, deployment target 26.0). The plugin keeps working on older Macs without the app.
- Swift language mode 6 for `EarshotKit` and the app.
- App socket: `~/Library/Application Support/Earshot/earshot.sock`, mode 0600. One JSON object per line, field `"v": 1`.
- The plugin waits at most 200 ms for the app's answer; any other outcome means the plugin plays the line itself. Each line plays exactly once.
- Line kinds are the plugin's own: `need`, `reply`, `alert`, `done`, `beat`, `ack`, `roll`, `intro`.
- Held during calls: `need`, `reply`, `alert`, `done`. Dropped during calls: `beat`, `ack`. `roll` plays even while the mic is busy.
- A line that waits more than 60 s in the queue is dropped. Held lines older than 4 hours are dropped.
- Catch-up: per session the first `need` line and the newest line of each other kind; order need/reply, then alert, then done, oldest first; "While you were on the mic:" when the oldest kept line is 30 s or older; at most 4 lines, then "And N more."
- Lowering other audio: fade to the set level (default 30%) over 200 ms, back over 200 ms; tap only while speaking; never record or save audio.
- Config file: `~/.config/earshot/config`, shell `KEY=value` lines, mode 0600, shared with the plugin.
- Copy rules: no em dashes anywhere (code comments, UI text, docs). Plain wording.
- Bundle ID `com.earshot.app`, Team ID `8N9KUZLT8N`, unified log subsystem `com.earshot.app`.

## Review Focus

- **The app is running but hung or slow:** the plugin must still say the line within about 0.2 s, never twice, never zero times. Pinned in Task 10 (silent fake app).
- **A call starts while Earshot is mid-line:** the line stops and is said in the catch-up, with the lines queued behind it. Pinned in Task 5 (barge-in test).
- **Ducking left on:** if the app stops speaking, crashes in a line, or quits, other apps must not stay quiet or muted. Pinned in Task 8 (end restores, destroy on stop) and Task 12 (quit tears down).
- **The config file has values setup.sh wrote with `printf %q`** (backslash escapes, `$'...'`): the app must read them the way bash does for the values Earshot uses. Pinned in Task 3.
- **Existing plugin tests run on a Mac where the app is running:** they must not hand lines to the real app. Pinned in Task 10 (DRYRUN without EARSHOT_APP_SOCK skips the app).

## Deviations from the spec (decided while planning)

- Stop: the probe on 2026-10-11 showed `now` does not interrupt (spec updated).
- The wake word power probe moves to plan 2, because it only affects listening.
- The ElevenLabs key stays in the config file in plan 1. A Keychain item made by the app would make `security` show an access prompt when a hook reads it. Plan 2 revisits this with an access list that trusts `/usr/bin/security`.
- The Kokoro helper (`tts/`) stays as it is, because it supports macOS 15 and the app needs macOS 26. The app has its own small Kokoro engine on the same FluidAudio version and shares the plugin's audio cache.
- The Voice tab has no speed setting yet (the plugin has none either).
- The mute file gains an optional end time, so "Mute for 1 hour" survives the app quitting.

```swift
import Foundation

/// Kinds of spoken lines, named as the plugin names them (see `tell` in speak.sh).
public enum LineKind: String, Codable, Sendable, CaseIterable {
    case need, reply, alert, done, beat, ack, roll, intro

    /// Kept for the catch-up while another app uses the mic. Progress updates
    /// and "On it" are stale by then.
    public var isHeld: Bool {
        switch self {
        case .need, .reply, .alert, .done: true
        default: false
        }
    }

    /// Catch-up order: lines that need you, then alerts, then finished lines.
    public var catchUpRank: Int {
        switch self {
        case .need, .reply: 0
        case .alert: 1
        default: 2
        }
    }
}

/// What a session is doing, as speak.sh's set_status says it, plus `closed`.
public enum SessionState: String, Codable, Sendable {
    case open, working, needs, reply, stuck, failed, done, closed
}

/// One message from the plugin: one JSON object per line.
public enum AppMessage: Sendable, Equatable {
    case say(Say)
    case status(Status)

    public static let version = 1

    public struct Say: Codable, Sendable, Equatable {
        public var text: String
        public var kind: LineKind
        public var session: String
        public var name: String?
        public var transcript: String?

        public init(text: String, kind: LineKind, session: String, name: String? = nil, transcript: String? = nil) {
            self.text = text; self.kind = kind; self.session = session
            self.name = name; self.transcript = transcript
        }

        public init(from decoder: any Decoder) throws {
            let c = try decoder.container(keyedBy: CodingKeys.self)
            text = try c.decode(String.self, forKey: .text)
            kind = try c.decode(LineKind.self, forKey: .kind)
            session = try c.decodeIfPresent(String.self, forKey: .session) ?? ""
            name = try c.decodeIfPresent(String.self, forKey: .name)
            transcript = try c.decodeIfPresent(String.self, forKey: .transcript)
        }
    }

    public struct Status: Codable, Sendable, Equatable {
        public var session: String
        public var state: SessionState
        public var detail: String?
        public var name: String?
        public var project: String?
        public var title: String?

        public init(session: String, state: SessionState, detail: String? = nil, name: String? = nil,
                    project: String? = nil, title: String? = nil) {
            self.session = session; self.state = state; self.detail = detail
            self.name = name; self.project = project; self.title = title
        }
    }

    public enum DecodeError: Error, Equatable {
        case badMessage
        case version(Int)
        case unknownType(String)
    }

    private struct Envelope: Decodable { let v: Int; let type: String }

    public static func decode(_ line: Data) throws(DecodeError) -> AppMessage {
        let d = JSONDecoder()
        guard let env = try? d.decode(Envelope.self, from: line) else { throw .badMessage }
        guard env.v == version else { throw .version(env.v) }
        switch env.type {
        case "say":
            guard let s = try? d.decode(Say.self, from: line) else { throw .badMessage }
            return .say(s)
        case "status":
            guard let s = try? d.decode(Status.self, from: line) else { throw .badMessage }
            return .status(s)
        default:
            throw .unknownType(env.type)
        }
    }
}

/// The app's answer to each message.
public struct AppReply: Codable, Sendable, Equatable {
    public var ok: Bool
    public var reason: String?

    public init(ok: Bool, reason: String? = nil) { self.ok = ok; self.reason = reason }

    public var encoded: Data {
        let e = JSONEncoder()
        e.outputFormatting = [.sortedKeys]
        return (try? e.encode(self)) ?? Data(#"{"ok":false}"#.utf8)
    }
}
```

```swift
import Darwin

/// sockaddr_un for a path. sun_path holds 104 bytes on macOS, the last one the
/// terminating zero.
enum UnixAddress {
    static func fits(_ path: String) -> Bool { path.utf8.count < 104 }

    static func with<T>(_ path: String, _ body: (UnsafePointer<sockaddr>, socklen_t) -> T) -> T {
        var addr = sockaddr_un()
        addr.sun_family = sa_family_t(AF_UNIX)
        addr.sun_len = UInt8(MemoryLayout<sockaddr_un>.size)
        let bytes = Array(path.utf8.prefix(103))
        withUnsafeMutableBytes(of: &addr.sun_path) { buf in
            for (i, b) in bytes.enumerated() { buf[i] = b }
            buf[bytes.count] = 0
        }
        return withUnsafePointer(to: &addr) {
            $0.withMemoryRebound(to: sockaddr.self, capacity: 1) { body($0, socklen_t(MemoryLayout<sockaddr_un>.size)) }
        }
    }

    static func noSigPipe(_ fd: Int32) {
        var on: Int32 = 1
        setsockopt(fd, SOL_SOCKET, SO_NOSIGPIPE, &on, socklen_t(MemoryLayout<Int32>.size))
    }
}
```

```swift
import Darwin
import Foundation

/// A Unix socket that answers one line with one line. Lines are newline
/// terminated. Each client may send several lines; the handler runs on one
/// serial queue, so lines are handled in the order they arrive.
public final class LineServer: @unchecked Sendable {
    public enum Failure: Error { case pathTooLong, socket(Int32), bind(Int32) }

    private let path: String
    private let handler: @Sendable (Data) -> Data
    private let queue = DispatchQueue(label: "com.earshot.app.lineserver")
    private var listenSource: DispatchSourceRead?
    private var clients: [Int32: DispatchSourceRead] = [:]
    private var buffers: [Int32: Data] = [:]
    private static let maxLine = 1 << 16

    public init(path: String, handler: @escaping @Sendable (Data) -> Data) {
        self.path = path
        self.handler = handler
    }

    public func start() throws {
        guard UnixAddress.fits(path) else { throw Failure.pathTooLong }
        let dir = (path as NSString).deletingLastPathComponent
        try FileManager.default.createDirectory(atPath: dir, withIntermediateDirectories: true,
                                                attributes: [.posixPermissions: 0o700])
        unlink(path)   // left by an app that crashed; one instance runs at a time
        let fd = socket(AF_UNIX, SOCK_STREAM, 0)
        guard fd >= 0 else { throw Failure.socket(errno) }
        let bound = UnixAddress.with(path) { bind(fd, $0, $1) }
        guard bound == 0, chmod(path, 0o600) == 0, listen(fd, 32) == 0 else {
            let e = errno
            close(fd)
            throw Failure.bind(e)
        }
        _ = fcntl(fd, F_SETFL, O_NONBLOCK)
        let source = DispatchSource.makeReadSource(fileDescriptor: fd, queue: queue)
        source.setEventHandler { [weak self] in self?.acceptAll(fd) }
        source.setCancelHandler { close(fd) }
        listenSource = source
        source.resume()
    }

    public func stop() {
        queue.sync {
            for fd in Array(clients.keys) { drop(fd) }
            listenSource?.cancel()
            listenSource = nil
        }
        unlink(path)
    }

    private func acceptAll(_ listenFD: Int32) {
        while true {
            let fd = accept(listenFD, nil, nil)
            guard fd >= 0 else { return }
            _ = fcntl(fd, F_SETFL, O_NONBLOCK)
            UnixAddress.noSigPipe(fd)
            let source = DispatchSource.makeReadSource(fileDescriptor: fd, queue: queue)
            source.setEventHandler { [weak self] in self?.readClient(fd) }
            source.setCancelHandler { close(fd) }
            clients[fd] = source
            buffers[fd] = Data()
            source.resume()
        }
    }

    private func readClient(_ fd: Int32) {
        var chunk = [UInt8](repeating: 0, count: 4096)
        let n = read(fd, &chunk, chunk.count)
        if n < 0, errno == EAGAIN { return }
        guard n > 0 else { drop(fd); return }
        buffers[fd, default: Data()].append(contentsOf: chunk[0..<n])
        while let buffer = buffers[fd], let nl = buffer.firstIndex(of: 10) {
            let line = Data(buffer[buffer.startIndex..<nl])
            buffers[fd] = Data(buffer[buffer.index(after: nl)...])
            var reply = handler(line)
            reply.append(10)
            // Replies are a few bytes, well under the socket buffer.
            _ = reply.withUnsafeBytes { write(fd, $0.baseAddress, $0.count) }
        }
        if (buffers[fd]?.count ?? 0) > Self.maxLine { drop(fd) }
    }

    private func drop(_ fd: Int32) {
        clients.removeValue(forKey: fd)?.cancel()
        buffers[fd] = nil
    }
}
```

```swift
import Darwin
import Foundation

/// Sends one line to a LineServer-style socket and waits for one line back.
public enum LineClient {
    public enum Failure: Error, Equatable { case pathTooLong, connect(Int32), write, timeout, closed }

    public static func send(path: String, line: Data, timeout: TimeInterval) throws(Failure) -> Data {
        guard UnixAddress.fits(path) else { throw .pathTooLong }
        let fd = socket(AF_UNIX, SOCK_STREAM, 0)
        guard fd >= 0 else { throw .connect(errno) }
        defer { close(fd) }
        UnixAddress.noSigPipe(fd)
        guard UnixAddress.with(path, { connect(fd, $0, $1) }) == 0 else { throw .connect(errno) }
        var out = line
        out.append(10)
        let sent = out.withUnsafeBytes { write(fd, $0.baseAddress, $0.count) }
        guard sent == out.count else { throw .write }
        let deadline = Date().addingTimeInterval(timeout)
        var reply = Data()
        var byte: UInt8 = 0
        while true {
            let ms = Int32(max(0, deadline.timeIntervalSinceNow * 1000))
            var pfd = pollfd(fd: fd, events: Int16(POLLIN), revents: 0)
            guard poll(&pfd, 1, ms) > 0 else { throw .timeout }
            let n = read(fd, &byte, 1)
            if n <= 0 {
                if reply.isEmpty { throw .closed }
                return reply
            }
            if byte == 10 { return reply }
            reply.append(byte)
        }
    }
}
```

```swift
import Foundation

extension URL {

    public static var earshotDir: URL {
        FileManager.default.homeDirectoryForCurrentUser.appending(path: ".config/earshot")

    public static var earshotConfig: URL { earshotDir.appending(path: "config") }

/// The plugin's config file: shell lines `KEY=value` that speak.sh sources.
/// setup.sh writes values with `printf %q`; this reads the forms that produces
/// (plain, backslash escapes, '...', "...", $'...') and writes '...'.
public struct EarshotConfig: Sendable, Equatable {
    public enum Engine: String, Sendable, CaseIterable { case kokoro, elevenlabs, say }

    private var lines: [String]

    public init(text: String) {
        lines = text.split(separator: "\n", omittingEmptySubsequences: false).map(String.init)
        if lines.last == "" { lines.removeLast() }
    }

    public static func load(from url: URL = .earshotConfig) -> EarshotConfig {
        EarshotConfig(text: (try? String(contentsOf: url, encoding: .utf8)) ?? "")
    }

    public var text: String { lines.isEmpty ? "" : lines.joined(separator: "\n") + "\n" }

    public func save(to url: URL = .earshotConfig) throws {
        try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true,
                                                attributes: [.posixPermissions: 0o700])
        let tmp = url.appendingPathExtension("tmp")
        FileManager.default.createFile(atPath: tmp.path, contents: Data(text.utf8), attributes: [.posixPermissions: 0o600])
        _ = try FileManager.default.replaceItemAt(url, withItemAt: tmp)
        chmod(url.path, 0o600)
    }

    public subscript(_ key: String) -> String? {
        for line in lines.reversed() {
            if let (k, v) = Self.parse(line), k == key { return v }
        }
        return nil
    }

    /// Sets a key in place (every earlier copy is removed), or appends it.
    /// nil removes the key.
    public mutating func set(_ key: String, _ value: String?) {
        let indices = lines.indices.filter { Self.parse(lines[$0])?.0 == key }
        let newLine = value.map { "\(key)=\(Self.quote($0))" }
        if let first = indices.first, let newLine {
            lines[first] = newLine
            for i in indices.dropFirst().reversed() { lines.remove(at: i) }
        } else {
            for i in indices.reversed() { lines.remove(at: i) }
            if let newLine { lines.append(newLine) }
        }
    }

    // MARK: Typed values, with speak.sh's defaults

    public var engine: Engine {
        if let e = self["EARSHOT_ENGINE"], !e.isEmpty { return Engine(rawValue: e) ?? .kokoro }
        return (elevenLabsKey ?? "").isEmpty ? .kokoro : .elevenlabs
    }
    public var level: String { nonEmpty("EARSHOT_LEVEL") ?? "normal" }
    public var style: String { nonEmpty("EARSHOT_STYLE") ?? "plain" }
    public var elevenLabsKey: String? { nonEmpty("EARSHOT_KEY") }
    public var elevenLabsVoice: String? { nonEmpty("EARSHOT_VOICE") }
    public var elevenLabsModel: String { nonEmpty("EARSHOT_MODEL") ?? "eleven_v4_turbo" }
    public var kokoroVoice: String { nonEmpty("EARSHOT_KOKORO_VOICE") ?? "af_heart" }
    public var sayVoice: String? { nonEmpty("EARSHOT_SAY_VOICE") }
    /// App only: lower other apps' audio while Earshot talks.
    public var duckEnabled: Bool { self["EARSHOT_DUCK"] != "off" }
    /// App only: how loud other apps stay, 10 to 90 percent.
    public var duckLevel: Float {
        guard let s = self["EARSHOT_DUCK_LEVEL"], let p = Int(s) else { return 0.3 }
        return Float(min(max(p, 10), 90)) / 100
    }

    private func nonEmpty(_ key: String) -> String? {
        guard let v = self[key], !v.isEmpty else { return nil }
        return v
    }

    // MARK: Shell quoting

    static func quote(_ value: String) -> String {
        "'" + value.replacingOccurrences(of: "'", with: #"'\''"#) + "'"
    }

    /// `KEY=value` with the value unquoted the way bash would, for one word.
    static func parse(_ line: String) -> (String, String)? {
        guard let eq = line.firstIndex(of: "="),
              line[..<eq].allSatisfy({ $0.isLetter || $0.isNumber || $0 == "_" }),
              !line[..<eq].isEmpty, !line.hasPrefix("#") else { return nil }
        return (String(line[..<eq]), unquote(line[line.index(after: eq)...]))
    }

    static func unquote(_ s: Substring) -> String {
        var out = ""
        var i = s.startIndex
        while i < s.endIndex {
            let c = s[i]
            if c == "'" {
                i = s.index(after: i)
                while i < s.endIndex, s[i] != "'" { out.append(s[i]); i = s.index(after: i) }
            } else if c == "$", s.index(after: i) < s.endIndex, s[s.index(after: i)] == "'" {
                i = s.index(i, offsetBy: 2)
                while i < s.endIndex, s[i] != "'" {
                    if s[i] == "\\", s.index(after: i) < s.endIndex {
                        i = s.index(after: i)
                        switch s[i] { case "n": out.append("\n"); case "t": out.append("\t"); default: out.append(s[i]) }
                    } else { out.append(s[i]) }
                    i = s.index(after: i)
                }
            } else if c == "\"" {
                i = s.index(after: i)
                while i < s.endIndex, s[i] != "\"" {
                    if s[i] == "\\", s.index(after: i) < s.endIndex { i = s.index(after: i) }
                    out.append(s[i]); i = s.index(after: i)
                }
            } else if c == "\\", s.index(after: i) < s.endIndex {
                i = s.index(after: i); out.append(s[i])
            } else if c == " " || c == "#" {
                break   // end of the word, or a comment after it
            } else {
                out.append(c)
            }
            if i < s.endIndex { i = s.index(after: i) }
        }
        return out
    }
}
```

```swift
import Foundation

/// One line to say.
public struct SpokenLine: Sendable, Equatable, Identifiable {
    public let id: UUID
    public var text: String
    public var kind: LineKind
    public var session: String
    /// The session's transcript, for lines that wait on you: a newer
    /// transcript means you answered, for example with Esc, which fires no hook.
    public var transcript: String?
    public var received: Date

    public init(id: UUID = UUID(), text: String, kind: LineKind, session: String, transcript: String? = nil,
                received: Date = Date()) {
        self.id = id; self.text = text; self.kind = kind; self.session = session
        self.transcript = transcript; self.received = received
    }

    /// speak.sh's still_waiting, turned around: the transcript changed more
    /// than 2 seconds after the line arrived.
    public static func transcriptAnswered(_ line: SpokenLine) -> Bool {
        guard let path = line.transcript,
              let modified = (try? FileManager.default.attributesOfItem(atPath: path))?[.modificationDate] as? Date
        else { return false }
        return modified.timeIntervalSince(line.received) > 2
    }
}
```

```swift
import Foundation

/// Lines kept while another app uses the mic, and the order they are said in
/// afterwards. A port of catch_up in speak.sh.
public struct HoldQueue: Sendable {
    public static let maxAge: TimeInterval = 4 * 3600
    static let introAge: TimeInterval = 30
    static let maxLines = 4

    private var lines: [SpokenLine] = []

    public init() {}

    public var isEmpty: Bool { lines.isEmpty }
    public var count: Int { lines.count }

    public mutating func hold(_ line: SpokenLine) {
        guard line.kind.isHeld else { return }
        lines.append(line)
    }

    /// You answered this session, so its "needs you" lines are stale.
    public mutating func dropAnswered(session: String) {
        lines.removeAll { $0.session == session && ($0.kind == .need || $0.kind == .reply) }
    }

    /// Takes every held line and returns what to say, in order.
    public mutating func takeCatchUp(now: Date, answered: (SpokenLine) -> Bool) -> [SpokenLine] {
        let batch = lines.filter { now.timeIntervalSince($0.received) <= Self.maxAge }
        lines.removeAll()
        // Per session and kind: the first "needs you" line, the most specific
        // one, and the newest line of every other kind.
        var picked: [String: SpokenLine] = [:]
        for line in batch {
            let key = line.session + "\u{1f}" + line.kind.rawValue
            if line.kind != .need || picked[key] == nil { picked[key] = line }
        }
        let kept = picked.values
            .filter { !($0.kind == .need && answered($0)) }
            .sorted { ($0.kind.catchUpRank, $0.received) < ($1.kind.catchUpRank, $1.received) }
        guard let oldest = kept.map(\.received).min() else { return [] }
        var out: [SpokenLine] = []
        if now.timeIntervalSince(oldest) >= Self.introAge {
            out.append(SpokenLine(text: "While you were on the mic:", kind: .intro, session: "", received: now))
        }
        out += kept.prefix(Self.maxLines)
        if kept.count > Self.maxLines {
            out.append(SpokenLine(text: "And \(kept.count - Self.maxLines) more.", kind: .intro, session: "", received: now))
        }
        return out
    }
}
```

```swift
import Foundation
import os

public protocol Synthesizer: Sendable {
    /// An audio file for the line, or nil when every engine failed.
    func audio(for line: SpokenLine) async -> URL?
}

public protocol LinePlayer: Sendable {
    /// Plays the file. True when it played to the end, false when stopped.
    func play(_ url: URL) async -> Bool
    func stop() async
}

public protocol MicSource: Sendable {
    /// Another app captures from the mic (a call, dictation).
    var isBusy: Bool { get async }
    /// Every change of isBusy.
    func changes() -> AsyncStream<Bool>
}

public protocol Ducking: Sendable {
    func begin() async
    func end() async
}

/// The one speaker all sessions share: lines take turns, wait while another
/// app uses the mic, and are said in a catch-up afterwards.
public actor SpeechOut {
    public enum State: Sendable, Equatable { case idle, speaking, holding }

    public static let errorTone = URL(fileURLWithPath: "/System/Library/Sounds/Basso.aiff")
    private let log = Logger(subsystem: "com.earshot.app", category: "speech")

    private let synth: any Synthesizer
    private let player: any LinePlayer
    private let mic: any MicSource
    private let ducker: any Ducking
    private let answered: @Sendable (SpokenLine) -> Bool
    private let settle: Duration
    private let maxWait: TimeInterval
    private let clock: @Sendable () -> Date

    private var queue: [SpokenLine] = []
    private var held = HoldQueue()
    private var running = false
    private var micBusy = false
    private var interrupted = false
    private var catchUpGeneration = 0
    private var idleWaiters: [CheckedContinuation<Void, Never>] = []
    private var stateConts: [UUID: AsyncStream<State>.Continuation] = [:]
    public private(set) var state: State = .idle { didSet { if state != oldValue { stateConts.values.forEach { $0.yield(state) } } } }

    public init(synth: any Synthesizer, player: any LinePlayer, mic: any MicSource, ducker: any Ducking,
                answered: @escaping @Sendable (SpokenLine) -> Bool = SpokenLine.transcriptAnswered,
                settle: Duration = .seconds(4), maxWait: TimeInterval = 60,
                clock: @escaping @Sendable () -> Date = Date.init) {
        self.synth = synth; self.player = player; self.mic = mic; self.ducker = ducker
        self.answered = answered; self.settle = settle; self.maxWait = maxWait; self.clock = clock
    }

    /// Starts following the mic. Call once.
    public func start() async {
        micBusy = await mic.isBusy
        let changes = mic.changes()
        Task { [weak self] in
            for await busy in changes { await self?.micChanged(busy) }
        }
    }

    public func stateChanges() -> AsyncStream<State> {
        let (stream, cont) = AsyncStream<State>.makeStream()
        let id = UUID()
        stateConts[id] = cont
        cont.yield(state)
        cont.onTermination = { [weak self] _ in Task { await self?.removeStateCont(id) } }
        return stream
    }
    private func removeStateCont(_ id: UUID) { stateConts[id] = nil }

    public func enqueue(_ line: SpokenLine) {
        if line.kind != .roll && micBusy {
            hold(line)
            return
        }
        queue.append(line)
        runIfNeeded()
    }

    /// The session's prompt was answered, so its held "needs you" lines are stale.
    public func sessionAnswered(_ session: String) {
        held.dropAnswered(session: session)
        updateState()
    }

    /// Returns when nothing is queued or playing.
    public func waitUntilIdle() async {
        if !running && queue.isEmpty { return }
        await withCheckedContinuation { idleWaiters.append($0) }
    }

    // MARK: -

    private func hold(_ line: SpokenLine) {
        if line.kind.isHeld { log.info("held \(line.kind.rawValue, privacy: .public)") }
        held.hold(line)
        updateState()
    }

    private func runIfNeeded() {
        guard !running else { return }
        running = true
        Task { await run() }
    }

    private func run() async {
        var ducked = false
        while !queue.isEmpty {
            let line = queue.removeFirst()
            if clock().timeIntervalSince(line.received) > maxWait {
                log.info("dropped a line that waited over \(Int(self.maxWait)) s")
                continue
            }
            if line.kind != .roll && micBusy { hold(line); continue }
            let url = await synth.audio(for: line) ?? Self.errorTone
            // A call may have started while the audio was made.
            if line.kind != .roll && micBusy { hold(line); continue }
            if !ducked { await ducker.begin(); ducked = true }
            interrupted = false
            state = .speaking
            let finished = await player.play(url)
            if !finished && interrupted {
                // A call started mid-line: say this line and the rest later.
                hold(line)
                for rest in queue where rest.kind != .roll { hold(rest) }
                queue.removeAll { $0.kind != .roll }
            }
        }
        if ducked { await ducker.end() }
        running = false
        updateState()
        let waiters = idleWaiters
        idleWaiters.removeAll()
        waiters.forEach { $0.resume() }
    }

    private func micChanged(_ busy: Bool) async {
        guard busy != micBusy else { return }
        micBusy = busy
        catchUpGeneration += 1
        if busy {
            if state == .speaking {
                interrupted = true
                await player.stop()
            }
            updateState()
            return
        }
        guard !held.isEmpty else { return }
        // Free for a few seconds in a row: a short pause in a call does not count.
        let generation = catchUpGeneration
        Task { [settle] in
            try? await Task.sleep(for: settle)
            await self.catchUp(ifStill: generation)
        }
    }

    private func catchUp(ifStill generation: Int) {
        guard generation == catchUpGeneration, !micBusy else { return }
        let lines = held.takeCatchUp(now: clock(), answered: answered)
        // Catch-up lines were already waiting; they count as new for the 60 s rule.
        let now = clock()
        queue.append(contentsOf: lines.map { var l = $0; l.received = now; return l })
        updateState()
        runIfNeeded()
    }

    private func updateState() {
        if running && state == .speaking { return }
        state = held.isEmpty ? (running ? .speaking : .idle) : .holding
    }
}
```

```swift
import CryptoKit
import Foundation
import os

public protocol SpeechEngine: Sendable {
    var name: String { get }
    var fileExtension: String { get }
    /// The text speak.sh hashes for its cache file name, so both share a cache.
    func cacheKey(_ text: String) -> String
    func render(_ text: String, to url: URL) async throws
}

extension URL {
    /// speak.sh's CACHE: $(getconf DARWIN_USER_CACHE_DIR)earshot
    public static var earshotCache: URL {
        var buf = [CChar](repeating: 0, count: Int(PATH_MAX))
        let n = confstr(_CS_DARWIN_USER_CACHE_DIR, &buf, buf.count)
        let base = n > 0 ? String(cString: buf) : NSTemporaryDirectory()
        return URL(fileURLWithPath: base).appending(path: "earshot")
    }
}

/// Tries each engine in turn; the first that makes the line wins. Made lines
/// are cached, so a repeated line costs nothing.
public struct EngineChain: Synthesizer {
    public let engines: [any SpeechEngine]
    let cacheDir: URL
    private let log = Logger(subsystem: "com.earshot.app", category: "engines")

    public init(engines: [any SpeechEngine], cacheDir: URL = .earshotCache) {
        self.engines = engines
        self.cacheDir = cacheDir
    }

    /// The configured engine first, then the ones that need no setup.
    /// ElevenLabs without a key or voice is skipped. Kokoro joins as a fallback
    /// only when its models are already on this Mac, so a fallback never downloads.
    public static func make(config: EarshotConfig, kokoro: KokoroEngine?, kokoroReady: Bool = KokoroEngine.modelsPresent) -> EngineChain {
        var list: [any SpeechEngine] = []
        let say = SayEngine(voice: config.sayVoice)
        switch config.engine {
        case .elevenlabs:
            if let key = config.elevenLabsKey, let voice = config.elevenLabsVoice {
                list.append(ElevenLabsEngine(key: key, voice: voice, model: config.elevenLabsModel))
            }
            if let kokoro, kokoroReady { list.append(kokoro) }
        case .kokoro:
            if let kokoro { list.append(kokoro) }
        case .say:
            break
        }
        list.append(say)
        return EngineChain(engines: list)
    }

    static func cacheName(key: String, ext: String) -> String {
        Insecure.MD5.hash(data: Data(key.utf8)).map { String(format: "%02x", $0) }.joined() + "." + ext
    }

    public func audio(for line: SpokenLine) async -> URL? {
        try? FileManager.default.createDirectory(at: cacheDir, withIntermediateDirectories: true,
                                                 attributes: [.posixPermissions: 0o700])
        for engine in engines {
            let file = cacheDir.appending(path: Self.cacheName(key: engine.cacheKey(line.text), ext: engine.fileExtension))
            if let size = try? FileManager.default.attributesOfItem(atPath: file.path)[.size] as? Int, size > 0 {
                return file
            }
            // A unique file per attempt, so two lines never write the same file.
            let tmp = cacheDir.appending(path: "dl-\(UUID().uuidString).\(engine.fileExtension)")
            do {
                try await engine.render(line.text, to: tmp)
                _ = try? FileManager.default.removeItem(at: file)
                try FileManager.default.moveItem(at: tmp, to: file)
                return file
            } catch {
                try? FileManager.default.removeItem(at: tmp)
                log.error("\(engine.name, privacy: .public) failed: \(error.localizedDescription, privacy: .public)")
            }
        }
        return nil
    }
}
```

```swift
            p.arguments = args
            p.standardOutput = FileHandle.nullDevice
            p.standardError = FileHandle.nullDevice
            p.terminationHandler = { cont.resume(returning: $0.terminationStatus) }
            do { try p.run() } catch { cont.resume(throwing: error) }
        }
```

```swift
/// Kokoro on this Mac, kept loaded while in use. v3 throws on a few inputs, so
/// those get a second try on the legacy runtime, which loads only then.
/// Unloads after 10 idle minutes and when macOS is short on memory.
public actor KokoroEngine: SpeechEngine {

    private var legacy: KokoroAneManager?
    private var legacyFailed = false
    private var lastUse = Date()
    private var idleTask: Task<Void, Never>?
    private var pressure: DispatchSourceMemoryPressure?
    private let log = Logger(subsystem: "com.earshot.app", category: "kokoro")

    public init(voice: String) { self.voice = voice }

    public nonisolated var name: String { "kokoro" }
    public nonisolated var fileExtension: String { "wav" }
    public nonisolated func cacheKey(_ text: String) -> String { "kokoro \(voice) \(text)" }

    /// FluidAudio keeps its models in ~/.cache/fluidaudio/Models.
    public static var modelsPresent: Bool {
        let dir = FileManager.default.homeDirectoryForCurrentUser.appending(path: ".cache/fluidaudio/Models")
        let names = (try? FileManager.default.contentsOfDirectory(atPath: dir.path)) ?? []
        return names.contains { $0.lowercased().contains("kokoro") }
    }

    public func render(_ text: String, to url: URL) async throws {
        lastUse = Date()
        let wav: Data
        do {
            wav = try await loaded().synthesize(text: text, voice: voice)
        } catch {
            guard !legacyFailed else { throw error }
            if legacy == nil {
                do {
                    let m = KokoroAneManager(version: .legacy)
                    try await m.initialize(preloadVoices: [voice])
                    legacy = m
                } catch { legacyFailed = true; throw error }
            }
            wav = try await legacy!.synthesize(text: text, voice: voice)
        }
        try wav.write(to: url, options: .atomic)
        scheduleUnload()
    }

    /// Loads the model and warms it up with a long line, so the first real
    /// line is fast. Safe to call more than once.
    public func prepare() async {
        _ = try? await loaded().synthesize(
            text: "Still on the billing service, about six minutes in. Latest step: run the invoice tests again.", voice: voice)
        scheduleUnload()
    }

    public func unload() {
        if v3 != nil || legacy != nil { log.info("unloaded Kokoro") }
        v3 = nil; legacy = nil; legacyFailed = false
        idleTask?.cancel(); idleTask = nil
    }

    private func loaded() async throws -> KokoroAneManager {
        if let v3 { return v3 }
        let m = KokoroAneManager(version: .v3)
        try await m.initialize(preloadVoices: [voice])
        v3 = m
        watchMemory()
        return m
    }

    private func scheduleUnload() {
        idleTask?.cancel()
        idleTask = Task { [weak self] in
            try? await Task.sleep(for: KokoroEngine.idle)
            guard !Task.isCancelled else { return }
            await self?.unload()
        }
    }

    private func watchMemory() {
        guard pressure == nil else { return }
        let source = DispatchSource.makeMemoryPressureSource(eventMask: [.warning, .critical], queue: .global(qos: .utility))
        source.setEventHandler { [weak self] in Task { await self?.unload() } }
        source.resume()
        pressure = source
    }
}
```

```swift
/// Plays one file at a time. AVAudioPlayer releases the output when it stops,
/// so the audio hardware can sleep between lines.
public final class AudioFilePlayer: NSObject, LinePlayer, AVAudioPlayerDelegate, @unchecked Sendable {
    private let lock = NSLock()
    private var player: AVAudioPlayer?
    private var waiter: CheckedContinuation<Bool, Never>?
    private let volume: Float
    private let log = Logger(subsystem: "com.earshot.app", category: "player")

    public init(volume: Float = 1) { self.volume = volume }

    public func play(_ url: URL) async -> Bool {
        await withCheckedContinuation { cont in
            lock.lock(); defer { lock.unlock() }
            do {
                let p = try AVAudioPlayer(contentsOf: url)
                p.volume = volume
                p.delegate = self
                guard p.play() else { throw CocoaError(.fileReadUnknown) }
                player = p
                waiter = cont
            } catch {
                log.error("couldn't play \(url.lastPathComponent, privacy: .public): \(error.localizedDescription, privacy: .public)")
                cont.resume(returning: true)   // nothing to wait for; the queue moves on
            }
        }
    }

    public func stop() async { finish(false) }

    public func audioPlayerDidFinishPlaying(_ p: AVAudioPlayer, successfully flag: Bool) { finish(true) }
    public func audioPlayerDecodeErrorDidOccur(_ p: AVAudioPlayer, error: (any Error)?) { finish(true) }

    private func finish(_ completed: Bool) {
        lock.lock()
        let w = waiter
        waiter = nil
        if !completed { player?.stop() }
        player = nil
        lock.unlock()
        w?.resume(returning: completed)
    }
}
```

```swift
import CoreAudio
import Darwin
import Foundation

/// Knows when another app captures from the mic, for example during a call
/// or while you dictate. Follows Core Audio's process list with property
/// listeners, so it costs nothing while nothing changes. Earshot itself and
/// always-on listeners (Siri, Voice Control) do not count.
public final class MicMonitor: MicSource, @unchecked Sendable {
    static let ignored = ["com.apple.corespeechd", "com.apple.SpeechRecognitionCore", "com.apple.speech.",
                          "com.apple.inputmethod.ironwood"]
    private let queue = DispatchQueue(label: "com.earshot.app.mic")
    private var watched: Set<AudioObjectID> = []
    private var busy = false
    private var conts: [UUID: AsyncStream<Bool>.Continuation] = [:]
    private let ownPID = getpid()

    public init() {
        queue.sync {
            var addr = Self.address(kAudioHardwarePropertyProcessObjectList)
            AudioObjectAddPropertyListenerBlock(AudioObjectID(kAudioObjectSystemObject), &addr, queue) { [weak self] _, _ in
                self?.rewatch()
                self?.refresh()
            }
            rewatch()
            busy = compute()
        }
    }

    public static func counts(bundleID: String) -> Bool {
        !ignored.contains { !bundleID.isEmpty && bundleID.hasPrefix($0) }
    }

    public var isBusy: Bool { get async { queue.sync { busy } } }

    public func changes() -> AsyncStream<Bool> {
        let (stream, cont) = AsyncStream<Bool>.makeStream()
        let id = UUID()
        queue.sync { conts[id] = cont }
        cont.onTermination = { [weak self] _ in self?.queue.async { self?.conts[id] = nil } }
        return stream
    }

    /// Each app that captures now and whether it counts, for diagnostics.
    public func appsUsingMic() -> [(bundleID: String, counts: Bool)] {
        queue.sync {
            Self.processes().compactMap { p in
                guard Self.uint(p, kAudioProcessPropertyIsRunningInput) != 0 else { return nil }
                let id = Self.bundleID(p)
                return (id, Self.pid(p) != ownPID && Self.counts(bundleID: id))
            }
        }
    }

    // MARK: - on queue

    private func rewatch() {
        for p in Self.processes() where !watched.contains(p) {
            watched.insert(p)
            var addr = Self.address(kAudioProcessPropertyIsRunningInput)
            AudioObjectAddPropertyListenerBlock(p, &addr, queue) { [weak self] _, _ in self?.refresh() }
        }
    }

    private func refresh() {
        let now = compute()
        guard now != busy else { return }
        busy = now
        conts.values.forEach { $0.yield(now) }
    }

    private func compute() -> Bool {
        Self.processes().contains { p in
            Self.uint(p, kAudioProcessPropertyIsRunningInput) != 0 && Self.pid(p) != ownPID
                && Self.counts(bundleID: Self.bundleID(p))
        }
    }

    // MARK: - Core Audio helpers

    static func address(_ selector: AudioObjectPropertySelector) -> AudioObjectPropertyAddress {
        AudioObjectPropertyAddress(mSelector: selector, mScope: kAudioObjectPropertyScopeGlobal,
                                   mElement: kAudioObjectPropertyElementMain)
    }

    static func processes() -> [AudioObjectID] {
        var addr = address(kAudioHardwarePropertyProcessObjectList)
        var size = UInt32(0)
        let system = AudioObjectID(kAudioObjectSystemObject)
        guard AudioObjectGetPropertyDataSize(system, &addr, 0, nil, &size) == noErr else { return [] }
        var list = [AudioObjectID](repeating: 0, count: Int(size) / MemoryLayout<AudioObjectID>.size)
        guard AudioObjectGetPropertyData(system, &addr, 0, nil, &size, &list) == noErr else { return [] }
        return list
    }

    static func uint(_ object: AudioObjectID, _ selector: AudioObjectPropertySelector) -> UInt32 {
        var addr = address(selector)
        var value = UInt32(0)
        var size = UInt32(MemoryLayout<UInt32>.size)
        return AudioObjectGetPropertyData(object, &addr, 0, nil, &size, &value) == noErr ? value : 0
    }

    static func pid(_ object: AudioObjectID) -> pid_t {
        var addr = address(kAudioProcessPropertyPID)
        var value = pid_t(0)
        var size = UInt32(MemoryLayout<pid_t>.size)
        return AudioObjectGetPropertyData(object, &addr, 0, nil, &size, &value) == noErr ? value : 0
    }

    static func bundleID(_ object: AudioObjectID) -> String {
        var addr = address(kAudioProcessPropertyBundleID)
        var value: Unmanaged<CFString>?
        var size = UInt32(MemoryLayout<Unmanaged<CFString>?>.size)
        guard AudioObjectGetPropertyData(object, &addr, 0, nil, &size, &value) == noErr else { return "" }
        return (value?.takeRetainedValue() as String?) ?? ""
    }
}
```

```swift
import AudioToolbox
import CoreAudio
import Foundation
import os

/// Lowers every other app's audio while Earshot talks. A Core Audio process
/// tap mutes the other apps and this plays their audio back quieter, fading
/// over 200 ms each way. The tap exists only while ducking; nothing is
/// recorded or saved. Needs the audio capture permission
/// (NSAudioCaptureUsageDescription); without it, begin() does nothing.
public actor TapDucker: Ducking {
    static let fade: Double = 0.2
    private let settings: @Sendable () -> (enabled: Bool, level: Float)
    private let log = Logger(subsystem: "com.earshot.app", category: "duck")
    private var tap = AudioObjectID(0)
    private var device = AudioDeviceID(0)
    private var proc: AudioDeviceIOProcID?
    private let gain = GainState()
    private var generation = 0
    public private(set) var lastError: OSStatus?

    public init(settings: @escaping @Sendable () -> (enabled: Bool, level: Float)) { self.settings = settings }

    public var isActive: Bool { device != 0 }
    public var callbacks: Int { gain.callbacks }

    public func begin() async {
        generation += 1
        let s = settings()
        guard s.enabled else { return }
        if device == 0 {
            do { try create() } catch {
                lastError = (error as? DuckError)?.status
                log.error("ducking failed: \(String(describing: error), privacy: .public)")
                teardown()
                return
            }
        }
        gain.setTarget(s.level)
    }

    public func end() async {
        guard device != 0 else { return }
        gain.setTarget(1)
        let g = generation
        try? await Task.sleep(for: .milliseconds(Int(Self.fade * 1000) + 50))
        // A new line started during the fade back: keep the tap.
        guard g == generation else { return }
        teardown()
    }

    /// Removes the tap at once, for quitting. Other apps play normally again.
    public func shutdown() { teardown() }

    // MARK: -

    struct DuckError: Error { let step: String; let status: OSStatus }

    private func create() throws {
        let system = AudioObjectID(kAudioObjectSystemObject)
        var pid = getpid()
        var me = AudioObjectID(0)
        var addr = MicMonitor.address(kAudioHardwarePropertyTranslatePIDToProcessObject)
        var size = UInt32(MemoryLayout<AudioObjectID>.size)
        _ = AudioObjectGetPropertyData(system, &addr, UInt32(MemoryLayout<pid_t>.size), &pid, &size, &me)

        let desc = CATapDescription(stereoGlobalTapButExcludeProcesses: me == 0 ? [] : [me])
        desc.uuid = UUID()
        desc.muteBehavior = .mutedWhenTapped
        desc.isPrivate = true
        desc.name = "Earshot"
        try check("create tap", AudioHardwareCreateProcessTap(desc, &tap))

        var out = AudioDeviceID(0)
        addr = MicMonitor.address(kAudioHardwarePropertyDefaultOutputDevice)
        size = UInt32(MemoryLayout<AudioDeviceID>.size)
        try check("output device", AudioObjectGetPropertyData(system, &addr, 0, nil, &size, &out))
        var uid: Unmanaged<CFString>?
        addr = MicMonitor.address(kAudioDevicePropertyDeviceUID)
        size = UInt32(MemoryLayout<Unmanaged<CFString>?>.size)
        try check("output uid", AudioObjectGetPropertyData(out, &addr, 0, nil, &size, &uid))
        let outUID = uid!.takeRetainedValue() as String

        let description: [String: Any] = [
            kAudioAggregateDeviceNameKey: "Earshot",
            kAudioAggregateDeviceUIDKey: UUID().uuidString,
            kAudioAggregateDeviceMainSubDeviceKey: outUID,
            kAudioAggregateDeviceIsPrivateKey: true,
            kAudioAggregateDeviceIsStackedKey: false,
            kAudioAggregateDeviceTapAutoStartKey: true,
            kAudioAggregateDeviceSubDeviceListKey: [[kAudioSubDeviceUIDKey: outUID]],
            kAudioAggregateDeviceTapListKey: [[kAudioSubTapDriftCompensationKey: true,
                                               kAudioSubTapUIDKey: desc.uuid.uuidString]],
        ]
        try check("aggregate", AudioHardwareCreateAggregateDevice(description as CFDictionary, &device))

        var rate = Float64(48_000)
        addr = MicMonitor.address(kAudioDevicePropertyNominalSampleRate)
        size = UInt32(MemoryLayout<Float64>.size)
        _ = AudioObjectGetPropertyData(device, &addr, 0, nil, &size, &rate)
        gain.reset(sampleRate: rate, fade: Self.fade)

        let g = gain
        try check("io proc", AudioDeviceCreateIOProcIDWithBlock(&proc, device, nil) { _, inData, _, outData, _ in
            g.render(UnsafeMutableAudioBufferListPointer(UnsafeMutablePointer(mutating: inData)),
                     UnsafeMutableAudioBufferListPointer(outData))
        })
        try check("start", AudioDeviceStart(device, proc))
        lastError = nil
        log.info("ducking on")
    }

    private func teardown() {
        if device != 0, let proc {
            AudioDeviceStop(device, proc)
            AudioDeviceDestroyIOProcID(device, proc)
        }
        if device != 0 { AudioHardwareDestroyAggregateDevice(device) }
        if tap != 0 { AudioHardwareDestroyProcessTap(tap); log.info("ducking off") }
        proc = nil; device = 0; tap = 0
    }

    private func check(_ step: String, _ status: OSStatus) throws {
        if status != noErr { throw DuckError(step: step, status: status) }
    }

    /// Gain for each frame: a straight line from `from` to `to` over `fade` seconds.
    static func gainRamp(from: Float, to: Float, frames: Int, sampleRate: Double, fade: Double) -> [Float] {
        let step = (to - from) / Float(max(1, sampleRate * fade))
        var g = from
        return (0..<frames).map { _ in
            defer { g = step < 0 ? max(to, g + step) : min(to, g + step) }
            return g
        }
    }
}

/// Shared with the real-time audio thread: plain stores, no locks, no allocation.
final class GainState: @unchecked Sendable {
    private var current: Float = 1
    private var target: Float = 1
    private var step: Float = 0
    private var stepSize: Float = 1.0 / 9600
    private(set) var callbacks = 0

    func reset(sampleRate: Double, fade: Double) {
        current = 1; target = 1; step = 0
        stepSize = 1 / Float(max(1, sampleRate * fade))
    }

    func setTarget(_ t: Float) {
        target = t
        step = (t - current) * stepSize
    }

    func render(_ ins: UnsafeMutableAudioBufferListPointer, _ outs: UnsafeMutableAudioBufferListPointer) {
        callbacks &+= 1
        let channels = max(1, ins.first.map { Int($0.mNumberChannels) } ?? 1)
        for i in 0..<outs.count {
            guard let dst = outs[i].mData?.assumingMemoryBound(to: Float.self) else { continue }
            let n = Int(outs[i].mDataByteSize) / MemoryLayout<Float>.size
            guard i < ins.count, let src = ins[i].mData?.assumingMemoryBound(to: Float.self) else {
                dst.update(repeating: 0, count: n)
                continue
            }
            let m = min(n, Int(ins[i].mDataByteSize) / MemoryLayout<Float>.size)
            var g = current
            for k in 0..<m {
                if k % channels == 0, g != target {
                    g += step
                    if (step < 0 && g < target) || (step > 0 && g > target) { g = target }
                }
                dst[k] = src[k] * g
            }
            if m < n { (dst + m).update(repeating: 0, count: n - m) }
            if i == outs.count - 1 || i == ins.count - 1 { current = g }
        }
    }
}
```

```swift
import Foundation

public struct SessionInfo: Sendable, Equatable, Identifiable {
    public let id: String
    public var name: String
    public var state: SessionState
    public var detail: String?
    public var updated: Date
}

/// Open sessions, from the plugin's status messages. Sessions that need you
/// come first, as in the roll call.
public actor SessionStore {
    private var byID: [String: SessionInfo] = [:]
    private var conts: [UUID: AsyncStream<[SessionInfo]>.Continuation] = [:]

    public init() {}

    /// Returns the state the session had before, if any.
    @discardableResult
    public func apply(_ status: AppMessage.Status) -> SessionState? {
        let before = byID[status.session]?.state
        if status.state == .closed {
            byID[status.session] = nil
        } else {
            let name = status.name ?? status.project ?? byID[status.session]?.name ?? "a session"
            byID[status.session] = SessionInfo(id: status.session, name: name, state: status.state,
                                               detail: status.detail, updated: Date())
        }
        let list = sessions
        conts.values.forEach { $0.yield(list) }
        return before
    }

    public var sessions: [SessionInfo] {
        byID.values.sorted { (Self.rank($0.state), $0.updated) < (Self.rank($1.state), $1.updated) }
    }

    public func changes() -> AsyncStream<[SessionInfo]> {
        let (stream, cont) = AsyncStream<[SessionInfo]>.makeStream()
        let id = UUID()
        conts[id] = cont
        cont.yield(sessions)
        cont.onTermination = { [weak self] _ in Task { await self?.remove(id) } }
        return stream
    }
    private func remove(_ id: UUID) { conts[id] = nil }

    static func rank(_ s: SessionState) -> Int {
        switch s {
        case .needs, .reply: 0
        case .stuck, .failed: 1
        case .working: 2
        case .done: 3
        case .open, .closed: 4
        }
    }
}
```

```swift
/// Wires the plugin socket to the speaker and the session list. Messages are
/// handled one at a time, in the order they arrive.
public final class EarshotCore: Sendable {
    public static var socketPath: String {
        FileManager.default.homeDirectoryForCurrentUser
            .appending(path: "Library/Application Support/Earshot/earshot.sock").path
    }

    public let speech: SpeechOut
    public let sessions: SessionStore
    public let events: EventLog
    private let server: LineServer
    private let inbox: AsyncStream<AppMessage>.Continuation
    private let stream: AsyncStream<AppMessage>

    public init(socketPath: String = EarshotCore.socketPath, speech: SpeechOut, sessions: SessionStore, events: EventLog) {
        self.speech = speech
        self.sessions = sessions
        self.events = events
        let (stream, inbox) = AsyncStream<AppMessage>.makeStream()
        self.stream = stream
        self.inbox = inbox
        server = LineServer(path: socketPath) { line in
            do {
                let message = try AppMessage.decode(line)
                inbox.yield(message)
                return AppReply(ok: true).encoded
            } catch .version {
                return AppReply(ok: false, reason: "version").encoded
            } catch {
                return AppReply(ok: false, reason: "unreadable").encoded
            }
        }
    }

    public func start() async throws {
        let (stream, speech, sessions, events) = (self.stream, self.speech, self.sessions, self.events)
        Task {
            for await message in stream {
                switch message {
                case .say(let s):
                    await events.add("line \(s.kind.rawValue)")
                    await speech.enqueue(SpokenLine(text: s.text, kind: s.kind, session: s.session, transcript: s.transcript))
                case .status(let s):
                    let before = await sessions.apply(s)
                    if before == .needs || before == .reply, s.state != .needs, s.state != .reply {
                        await speech.sessionAnswered(s.session)
                    }
                }
            }
        }
        try server.start()
        await events.add("listening for the plugin")
    }

    public func stop() {
        server.stop()
        inbox.finish()
    }

    /// The real thing: Kokoro, ElevenLabs and say from the config, the real
    /// player, mic and ducker. The config is read again for each line, so
    /// settings apply at once.
    public static func live(config: @escaping @Sendable () -> EarshotConfig) -> (core: EarshotCore, ducker: TapDucker, mic: MicMonitor) {
        let mic = MicMonitor()
        let ducker = TapDucker { let c = config(); return (c.duckEnabled, c.duckLevel) }
        let synth = LiveSynth(config: config)
        let speech = SpeechOut(synth: synth, player: AudioFilePlayer(), mic: mic, ducker: ducker)
        let core = EarshotCore(speech: speech, sessions: SessionStore(), events: EventLog())
        return (core, ducker, mic)
    }
}

/// Builds the engine chain from the config for each line, keeping one Kokoro
/// engine per voice so the model stays loaded.
final class LiveSynth: Synthesizer, @unchecked Sendable {
    private let config: @Sendable () -> EarshotConfig
    private let lock = NSLock()
    private var kokoro: KokoroEngine?

    init(config: @escaping @Sendable () -> EarshotConfig) { self.config = config }

    func audio(for line: SpokenLine) async -> URL? {
        let c = config()
        let k: KokoroEngine = lock.withLock {
            if let kokoro, kokoro.voice == c.kokoroVoice { return kokoro }
            let fresh = KokoroEngine(voice: c.kokoroVoice)
            kokoro = fresh
            return fresh
        }
        return await EngineChain.make(config: c, kokoro: k).audio(for: line)
    }
}
```

```swift
import AppKit
import EarshotKit
import Observation
import ServiceManagement
import SwiftUI

@MainActor @Observable
final class AppModel {
    var sessions: [SessionInfo] = []
    var speechState: SpeechOut.State = .idle
    var mutedUntil: Date?
    var config = EarshotConfig.load()
    var startError: String?
    var launchAtLogin = SMAppService.mainApp.status == .enabled

    @ObservationIgnored let updater = Updater()
    @ObservationIgnored private var core: EarshotCore?
    @ObservationIgnored private var ducker: TapDucker?
    @ObservationIgnored private var mic: MicMonitor?
    @ObservationIgnored private var muteTimer: Timer?
    @ObservationIgnored private let configBox = ConfigBox()

    static let muteFile = URL.earshotDir.appending(path: "mute")

    var menuIcon: String {
        if mutedUntil != nil { return "speaker.slash" }
        switch speechState {
        case .speaking: return "waveform"
        case .holding: return "pause.circle"
        case .idle: return "ear"
        }
    }

    func start() {
        configBox.value = config
        let box = configBox
        let live = EarshotCore.live { box.value }
        core = live.core; ducker = live.ducker; mic = live.mic
        readMute()
        Task {
            do { try await live.core.start() } catch { startError = "Couldn't open the plugin socket: \(error)" }
        }
        Task { for await list in await live.core.sessions.changes() { sessions = list } }
        Task { for await s in await live.core.speech.stateChanges() { speechState = s } }
        NotificationCenter.default.addObserver(forName: NSApplication.willTerminateNotification, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated { self?.shutdown() }
        }
    }

    func shutdown() {
        core?.stop()
        if let ducker { Task.detached { await ducker.shutdown() } }
    }

    // MARK: Settings

    func save(_ change: (inout EarshotConfig) -> Void) {
        var c = EarshotConfig.load()
        change(&c)
        try? c.save()
        config = c
        configBox.value = c
    }

    func setLaunchAtLogin(_ on: Bool) {
        do {
            if on { try SMAppService.mainApp.register() } else { try SMAppService.mainApp.unregister() }
        } catch {}
        launchAtLogin = SMAppService.mainApp.status == .enabled
    }

    func playTestLine() {
        guard let core else { return }
        Task { await core.speech.enqueue(SpokenLine(text: "This is how Earshot sounds.", kind: .roll, session: "")) }
    }

    // MARK: Mute

    func mute(for interval: TimeInterval) {
        let until = Date().addingTimeInterval(interval)
        try? FileManager.default.createDirectory(at: .earshotDir, withIntermediateDirectories: true)
        try? "\(Int(until.timeIntervalSince1970))\n".write(to: Self.muteFile, atomically: true, encoding: .utf8)
        setMuted(until)
    }

    func unmute() {
        try? FileManager.default.removeItem(at: Self.muteFile)
        setMuted(nil)
    }

    private func readMute() {
        guard let text = try? String(contentsOf: Self.muteFile, encoding: .utf8) else { return }
        let digits = text.filter(\.isNumber)
        if digits.isEmpty { mutedUntil = .distantFuture; return }
        let until = Date(timeIntervalSince1970: TimeInterval(digits) ?? 0)
        if until > Date() { setMuted(until) } else { unmute() }
    }

    private func setMuted(_ until: Date?) {
        mutedUntil = until
        muteTimer?.invalidate()
        guard let until, until != .distantFuture else { return }
        muteTimer = Timer.scheduledTimer(withTimeInterval: until.timeIntervalSinceNow, repeats: false) { [weak self] _ in
            MainActor.assumeIsolated { self?.unmute() }
        }
    }

    // MARK: Diagnostics

    func diagnostics() async -> String {
        let info = Bundle.main.infoDictionary ?? [:]
        let ver = "\(info["CFBundleShortVersionString"] ?? "?") (\(info["CFBundleVersion"] ?? "?"))"
        let events = await core?.events.recent ?? []
        let duckError = await ducker?.lastError
        let micApps = mic?.appsUsingMic().map { "\($0.bundleID.isEmpty ? "(no ID)" : $0.bundleID) \($0.counts ? "counts" : "ignored")" } ?? []
        return """
        Earshot \(ver)
        macOS \(ProcessInfo.processInfo.operatingSystemVersionString)
        Engine: \(config.engine.rawValue), level \(config.level), style \(config.style)
        Lower other audio: \(config.duckEnabled ? "on, \(Int(config.duckLevel * 100))%" : "off")\(duckError.map { ", last error \($0)" } ?? "")
        Kokoro models: \(KokoroEngine.modelsPresent ? "present" : "missing")
        Sessions: \(sessions.count)
        Mic in use by: \(micApps.isEmpty ? "nothing" : micApps.joined(separator: ", "))
        Recent events:
        \(events.joined(separator: "\n"))
        """
    }

    func copyDiagnostics() {
        Task {
            let text = await diagnostics()
            NSPasteboard.general.clearContents()
            NSPasteboard.general.setString(text, forType: .string)
        }
    }
}

/// The config the speech engines read, swapped whole when settings change.
final class ConfigBox: @unchecked Sendable {
    private let lock = NSLock()
    private var _value = EarshotConfig(text: "")
    var value: EarshotConfig {
        get { lock.withLock { _value } }
        set { lock.withLock { _value = newValue } }
    }
}
```

- [ ] **Step 2: Write `scripts/release-app.sh`**

```bash
#!/bin/bash
# Builds Earshot for Mac for release.
#   release-app.sh --local   Release build signed for this Mac, plus a DMG. No notarization.
#   release-app.sh           Developer ID build, notarized and stapled, a DMG, and the
#                            Sparkle appcast. Needs a "Developer ID Application" identity
#                            and a notarytool profile: xcrun notarytool store-credentials earshot
set -euo pipefail
ROOT=$(cd "$(dirname "$0")/.." && pwd); APP=$ROOT/app; OUT=$APP/build/release
fail() { echo "$*" >&2; exit 1; }
local_build=; [ "${1:-}" = --local ] && local_build=1
command -v xcodegen >/dev/null || fail "Needs XcodeGen: brew install xcodegen"
rm -rf "$OUT"; mkdir -p "$OUT"
(cd "$APP" && xcodegen generate >/dev/null)
ver=$(sed -n 's/^ *MARKETING_VERSION: "\(.*\)"/\1/p' "$APP/project.yml")

if [ -n "$local_build" ]; then
  xcodebuild -project "$APP/Earshot.xcodeproj" -scheme Earshot -configuration Release \
    -derivedDataPath "$APP/build" build >"$OUT/build.log" 2>&1 || fail "Build failed: $OUT/build.log"
  cp -R "$APP/build/Build/Products/Release/Earshot.app" "$OUT/"
else
  security find-identity -v -p codesigning | grep -q "Developer ID Application" \
    || fail "No Developer ID Application certificate. Create one at developer.apple.com > Certificates, then run this again."
  xcrun notarytool history --keychain-profile earshot >/dev/null 2>&1 \
    || fail "No notarytool profile. Run: xcrun notarytool store-credentials earshot"
  [ -n "${SPARKLE_PUBLIC_KEY:-}" ] || fail "Set SPARKLE_PUBLIC_KEY (from Sparkle's generate_keys)."
  xcodebuild -project "$APP/Earshot.xcodeproj" -scheme Earshot -configuration Release \
    -archivePath "$OUT/Earshot.xcarchive" SPARKLE_PUBLIC_KEY="$SPARKLE_PUBLIC_KEY" archive >"$OUT/build.log" 2>&1 \
    || fail "Archive failed: $OUT/build.log"
  xcodebuild -exportArchive -archivePath "$OUT/Earshot.xcarchive" -exportOptionsPlist "$APP/ExportOptions.plist" \
    -exportPath "$OUT" >>"$OUT/build.log" 2>&1 || fail "Export failed: $OUT/build.log"
  ditto -c -k --keepParent "$OUT/Earshot.app" "$OUT/Earshot.zip"
  xcrun notarytool submit "$OUT/Earshot.zip" --keychain-profile earshot --wait || fail "Notarization failed."
  xcrun stapler staple "$OUT/Earshot.app"
fi

dmg=$OUT/Earshot-$ver.dmg
hdiutil create -volname Earshot -srcfolder "$OUT/Earshot.app" -ov -format UDZO "$dmg" >/dev/null
if [ -z "$local_build" ]; then
  codesign --sign "Developer ID Application" "$dmg"
  xcrun notarytool submit "$dmg" --keychain-profile earshot --wait && xcrun stapler staple "$dmg"
  gen=$(find "$APP/build" -path '*Sparkle*/bin/generate_appcast' -type f | head -1)
  [ -x "$gen" ] && "$gen" "$OUT" || echo "generate_appcast not found: build once with Xcode to fetch Sparkle's tools."
fi
codesign --verify --deep --strict "$OUT/Earshot.app" && echo "Signature OK"
echo "Built $dmg"
```
